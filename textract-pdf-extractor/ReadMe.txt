# 💻 PDF document text extractor by Textract AWS

- upload text document and extract text from it
- to keep free of cost right now integrated only 'detect_document_text' api
- Further can be upgraded to 'analyse_document_text' api, if required - which is chargable version

## 🔧 Features
- can use text for another NLP model-- demo can work for downstream task
- Streamlit-based UI

## 📦 Setup

```bash
pip install -r requirements.txt
streamlit run app.py
