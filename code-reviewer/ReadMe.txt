# 💻 AI Code Reviewer with Claude (Bedrock)

# Tools, technology
Streamlit
python
AWS Bedrock - Claude 3 Haiku

- Choose task: review, find bugs, explain, or refactor
- Claude 3 Haiku via Bedrock
- Streamlit-based UI
