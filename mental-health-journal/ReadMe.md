# 🧠 Mental Health Journal Assistant

A privacy-friendly AI-powered journaling assistant that helps you reflect, summarize, and understand your emotional patterns using local language models. Built with **Streamlit**, **LangChain**, and **Ollama** for offline capability and personal use.

---

## 🚀 Features

- 📝 Write and store daily journal entries
- 🤖 Get a 3-paragraph reflective response from the AI
- 🧾 Receive a 1–2 sentence summary for quick insights
- ❤️ Detect the emotional sentiment (Positive / Negative / Neutral)
- 📅 View past summaries and track your emotional journey
- 💾 All data saved locally in a `.csv` file
- 🔒 Runs fully offline using **Ollama** + **LLaMA 3**
